# ⚔️ Software Engineer. Builder. Operator.

I am a **Software Engineer** from Kosovo with one clear direction:

> Build systems that look sharp, run fast, scale cleanly and solve real problems.

I do not build random screens.  
I build products with structure, logic, speed and purpose.

I care about the full machine:

- the interface users touch
- the API that moves the data
- the database that stores the truth
- the architecture that keeps everything clean
- the automation that removes manual work
- the deployment that makes it real
- the product thinking that makes people actually use it

My background in **Industrial Engineering with Informatics** gives me a different way of thinking: systems, processes, efficiency, structure and execution.
